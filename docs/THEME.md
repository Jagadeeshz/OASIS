# OASIS — theme and design system

OASIS uses **BINDU v4.0 / PRISM** (skill: `bindu-v4-design-system`) as its design language, bound to the OASIS palette: **deep void grounds → luminous yellow as the single interaction accent → spectrum colours as meaning**.

Everything is token-driven. No component contains a raw colour value; `src/theme/tokens.css` is the only place a colour literal exists outside the two canvas-painting fallbacks described in §7.

---

## 1. Files

| File | Role |
|---|---|
| `src/theme/tokens.css` | The system: colour, type, space, radius, depth, glass, rims, ambient light, motion, z-index, layout metrics; self-hosted font faces. |
| `src/theme/components.css` | Component layer: shell, primitives, workspaces, canvas, timeline, overlays. |
| `src/assets/fonts/*.woff2` | DM Sans 300–600, DM Mono 400/500, Cormorant Garamond 700 (downloaded once by `scripts/fetch-fonts.mjs`, bundled — no CDN at runtime). |
| `src/assets/oasis-mark.png` | In-app brand mark (generated by `scripts/make-mark.mjs`). |

`src/styles.css` (the previous single stylesheet) was removed; `src/main.tsx` imports tokens **before** components, per the skill's order.

## 2. Palette

**Ground (void family)** — `#09090B` window, `#101014` sidebar/behind, `#17171D` panel, `#1D1D24` raised/node, `#26262F` elevated, `#0C0C0F` sunken (inputs, stages), border `#303039` and `rgba(245,245,240,0.07)`.

**Text** — `#F5F5F0` primary, `#A5A5AD` secondary, `#8B8B94` muted, `rgba(245,245,240,0.28)` ghost, `#09090B` ink on yellow.

> Muted was raised from the brief's `#707078` to `#8B8B94`: `#707078` on the panel measured **3.64:1**, below WCAG AA for the 9.5–10px mono labels it is used on. `#8B8B94` measures **5.28:1**.

**Lumen (yellow)** — `#FFD400` main, `#FFE45C` bright, `#EAB900` deep, `rgba(255,212,0,0.18)` glow, `rgba(255,212,0,0.09)` selection fill, `rgba(255,212,0,0.42)` hairline, gradient `120deg bright → main → deep`.

**Spectrum** — violet `#8855FF`, blue `#398BFF`, cyan `#22D3EE`, green `#43D17A`, orange `#FF8A00`, red `#FF405F`, magenta `#D946EF`; gradient in prism order (violet → red).

**Meaning assigned to spectrum** (not decoration):

| Token | Meaning | Where |
|---|---|---|
| `--bindu-media-image` `#A78BFA` | image assets | asset cards, type badges, canvas ports |
| `--bindu-media-video` `#5EA6FF` | video | same |
| `--bindu-media-audio` `#22D3EE` | audio | same |
| `--bindu-media-text` `#FFA733` | prompt/text | canvas prompt ports, text clips |
| `--bindu-cat-input/model/generate/process/output` | workflow categories | node card header line + header glyph |
| `--bindu-ok/warn/danger/info/mock` | job + provider states | badges, notices, progress |

The spectrum gradient appears in exactly three places: the 1px topbar hairline, the sidebar edge rim, and the 2px rule on dashboard stat cards. That is the skill's "one spectrum moment per viewport" ceiling, deliberately under-used.

## 3. Type

Cormorant Garamond 700 for display (`h1`, `.stat .value` no longer — see §7), DM Sans 300/400/500/600 for UI, DM Mono 400/500 for labels, metrics and ids. Base `13px` (desktop scale), tracking `-0.011em` body, `0.10em` uppercase labels, `0.18em` brand.

Micro labels (`.field > label`, `table th`, `.nav-group`, `.stat .label`) are 9.5px uppercase mono — a deliberate pro-app density choice; all of them sit on the raised muted tone measured at 5.28:1.

---

## 4. Depth, glass, rims

Two-layer shadows per elevation, plus `inset 0 1px 0` top light on panels and node cards. Glass is restricted to things that overlap content: topbar, modals, drawer, toasts, floating canvas toolbar/hint. Primary panels are opaque — no blur behind a flat panel.

Edge rims: a 1px white-gradient `::before` at 14%→50%→14% on every `.panel`, and a spectral vertical rim on the sidebar edge.

Ambient: one multi-stop prism radial on `.app::before` (violet/blue/yellow at 6–9% alpha). No texture overlays behind text.

---

## 5. Interaction and motion

Yellow is the only interaction colour: primary buttons (ink text on yellow), active nav (yellow 2px bar + 9% fill), selection rings on nodes/clips/cards, focus rings (`outline: 2px solid` + glow on inputs), progress bars, playhead, tab indicator, active tab text.

Hover: +4% surface, border to `#303039`; buttons lift 1px on press (`ease-spring`); cards translate −2px and their thumbnails scale 1.03 over 400ms.

Motion durations and easing come from tokens (`120/200/400/420ms`, `cubic-bezier(0.25,0.46,0.45,0.94)`). Page entry fades up 6px; modals scale from 0.985; drawer slides 24px; toasts slide 8px. React Flow edges animate **only while a workflow is running** — motion communicates activity, not decoration. `prefers-reduced-motion` collapses every duration to 0.01ms at both the token and the rule level.

## 6. Where the brief and the skill conflict

The skill's hard rule 2 is "soma gold → CTA buttons ONLY". The OASIS brief explicitly makes yellow the dominant interaction colour (active nav, selection, progress, focus). Resolution, applied consistently:

- **Kept from the skill:** no yellow body copy, no yellow headings, no yellow page fills, no gradient text, no gradient CTA-on-gradient, spectrum never on text, one spectrum moment per viewport, logo as an image file.
- **Extended by the brief:** yellow also owns *interaction state* — nav indicator, selection rings, focus rings, progress, playhead, tab underline. It never owns a surface larger than a 9% wash or a 2px line.
- **Documented deviation** from the skill's gold `#C9911A` to the brand `#FFD400` (the brief's palette), which also raises ink-on-accent contrast from 7.1:1 to **13.9:1**.

## 7. Known issues and deliberate limits

1. **Stat numerals** were briefly set in Cormorant; the serif `1` reads as `I`. They now use DM Sans 600 with tabular numerals. Cormorant remains on `h1` only.
2. **Canvas colours painted by JS** (Video Studio preview letterbox and default title colour) cannot read CSS variables directly; they resolve tokens once through `cssToken()` with `black`/`white` keyword fallbacks. No hex exists in TS/TSX.
3. **Node zoom** — the canvas auto-fits the starter graph; with the inspector open the fit can reach ~0.86 zoom, so the inspector now collapses when nothing is selected (canvas gains ~312px). Node body type is 11px, ports 9.5px.
4. **Provider card heights** are unequal when one card has fewer fields (fal without endpoint/base URL). Grid stretches them; the shorter card keeps empty space rather than inventing filler.
5. **Installer icon** (`build/icon.png`) is unchanged from the previous build; the in-app mark is the new prism ring. Regenerating the installer icon is a packaging decision, not a runtime one.
6. **Legacy variable aliases** (`--bg`, `--panel`, `--line`, `--accent` …) still exist in `tokens.css` §15 so older component styles keep resolving; new CSS uses `--bindu-*` directly. Removing the aliases is a follow-up cleanup.
7. **41 unused tokens** remain defined (type scale, glass tiers, glow presets, direction-C/D geometry) — available for future surfaces, none referenced yet.
